# Security Policy

Wren is a desktop app that captures microphone audio and writes text into other
applications via the clipboard and synthetic keystrokes. We take security
reports seriously.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report privately through GitHub's [private vulnerability
reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(the **Security** tab → **Report a vulnerability**), or by email to
**hello@rafaelvieiras.com**.

Please include:

- A description of the issue and its impact.
- Steps to reproduce (a proof of concept if possible).
- The affected version / commit and your platform (Linux, macOS, Windows).

We aim to acknowledge reports within a few days and will keep you updated as we
work on a fix. Once a fix is released, we're happy to credit you unless you
prefer to stay anonymous.

## Supported versions

Wren is pre-1.0 and under active development. Security fixes land on the latest
release and on `master`. Older releases are not maintained.
